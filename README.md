This repository contains the script used to process single-cell RNA sequencing plates (CEl-seq2) for the publication:
Ramon-Zamorana, G. et al. Protein landscape of the chromatin domains in the malaria parasite Plasmodium falciparum. In submission (2026)

It contains a Quarto markdown document that processes the count matrices generated by UMI-tools demultiplexing in .tsv format. Count matrices are transformed in Seurat objects and analysed. 

If you want to reproduce keep in mind to:
- Change the top save and load locations, including annotations for your cell/gene matrix.
- Visually inspect the UMAP that is produced, use gene markers to select only the subset of cells/parasites that is of interest to you and subset these clusters from the total dataset.
- Chromosome names should be modified if you are not using the PF3D7_xxxxxx gene IDs, since now detection of chromosomes is based on this annotation PF3D7_yyxxxx with yy indicating the chromosome number the gene originates from.
